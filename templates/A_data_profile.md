# A_data_profile 模板

> 用途：A 建模手在建立模型前对数据的概况摸底（初步数据分析）。
> 负责人：A | 交接给：B | 输出：`02_model/A_data_profile.md`

## 数据概况

| 项 | 内容 |
|---|---|
| 数据文件 | 有哪些原始文件 |
| 样本量 | 行数、观测数量 |
| 变量 | 每个变量是什么 |
| 数据类型 | 连续/离散/分类/时间/空间 |
| 单位 | 是否统一 |

## 数据质量初步观察

| 项 | 内容 |
|---|---|
| 缺失 | 是否存在明显缺失 |
| 重复 | 是否存在明显重复 |
| 异常 | 是否存在明显异常值 |
| 分布 | 是否明显偏态/长尾等 |

## 结构特征

| 项 | 内容 |
|---|---|
| 时间结构 | 是否有时间序列特征 |
| 空间结构 | 是否有地区/坐标 |
| 变量关系 | 初步相关性/关联关系 |

## 建模可行性

- **数据可行性**：是否支持候选模型
- **数据风险**：哪些地方可能影响建模

## 验收

- [ ] 数据文件/样本量/变量/类型/单位已记录
- [ ] 缺失/重复/异常/分布已初步观察
- [ ] 数据可行性结论明确，风险已标注
