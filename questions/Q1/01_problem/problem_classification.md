## 第一问结构特征

- **响应变量**：连续型 Y 染色体浓度；实际比例/百分数尺度需 G3 核验。
- **核心解释变量**：连续孕周、BMI。
- **可选变量**：年龄、身高、体重、IVF、怀孕/生产次数、测序质量和染色体 Z 值等；是否纳入由数据审计与人类模型决策确定。
- **观测层级**：检测记录为行级观测，孕妇代码为个体级聚类标识。
- **重复测量**：同一孕妇可能有多次检测，必须考虑个体内依赖；不能默认所有行独立。
- **关系形式**：线性形式可作透明基线；孕周非线性、BMI 交互和异方差属于待验证结构，不是已确认事实。
- **推断目标**：孕周、BMI主效应及必要的非线性/交互项显著性；整体模型比较；重复测量处理是否必要；诊断与不确定性。
- **关联边界**：结果解释为统计关联，不作因果断言。

## 候选方法族（仅分类层级，不是最终模型）

1. 描述统计、Pearson/Spearman 相关与探索性可视化。
2. 可解释的连续响应回归，含线性项、必要时非线性项/交互项。
3. 重复测量回归：线性混合效应或聚类稳健推断，具体取舍交由 G2/G2.5。
4. 若 Y 浓度边界/偏态证据支持，可评估变换或广义响应模型；不得预先假定适用。
5. 稳健标准误、影响点分析、残差和异方差诊断作为推断验证组件，不单独算新的模型体系。

## 不适合直接作为第一问主线的方向

| 方向 | 不适合原因 |
|---|---|
| 纯时间序列预测 | 数据是不同孕妇的检测记录，孕周是个体内测量时间，不是单一均匀时间序列；题目要关系模型和显著性，不是未来值预测。 |
| 直接把所有记录当作独立普通回归 | 忽略同一孕妇多次检测的聚类依赖，可能低估标准误并夸大显著性。 |
| 黑箱深度学习 | 第一问强调关系解释和显著性，且当前数据结构/可用样本量/推断要求不支持把黑箱预测作为首选。 |
| 因果机制模型 | 题面提供观察性检测数据，不能仅凭相关分析确认孕周或 BMI 的生物因果作用。 |
| 第二问的时点优化模型 | 属于后续小问的决策目标，不应替代第一问的关系分析。 |

## 分类风险与待核验项

1. 男胎工作表名称可能出现编码乱码，需以列结构和 Y 浓度可观测性核验样本筛选。
2. Y 浓度实际尺度尚需确认；比例与百分数会影响解释和阈值，但不改变本层分类。
3. 孕妇代码是否完整、重复检测是否真正对应不同采血/检测需数据审计。
4. 孕周字符串解析、BMI/身高/体重单位和缺失机制可能影响可行方法。
5. 同一孕妇 BMI 是否固定、是否随检测记录变化需 G3 核验。
6. 非线性、交互和响应变换只有在数据诊断后才能进入候选优先级。
7. 外部文献检索当前受限（OpenAlex HTTP 429；AnySearch 结果未形成可用的交叉验证方法文献），不能把未核验文献当作分类依据。
