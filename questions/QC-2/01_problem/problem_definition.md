## 3. 决策目标（先说清"要回答什么"，不预写数值）

对每个规划日 d（d 从 2025.2.1 到 12.31）：

### 3.1 日前决策层（0:00，基于历史信息）
1. **输出** 0:00 制定的 144 点计划购电量 E_plan_d(t)（题目：其他时段购电费按此计算，一旦制定即锁定）。
2. **依据** 历史负载/光伏的联合残差情景，权衡"计划购电费（1×电价）"与"期望紧急购电费（5×电价）"。

### 3.2 日内执行层（实时，基于当前观测）
1. **输入** 当前时段真实净缺口 r_t = Load_t - PV_t - E_plan_t，当前库存 SOC_{t-1}。
2. **决策** 充电量 C_t 或放电量 D_t，平衡"当前紧急购电代价（5×电价）"与"未来库存价值（历史路径DP估计）"。
3. **输出** 实际执行的储能充放电及 SOC 轨迹，满足储能全部物理约束。
4. **输出** 实时紧急购电时段与电量（当计划购电+光伏+储能放电 < 真实负载时触发）。

### 3.3 评价标准
1. **主要指标**: 全年总购电费用 = Σ 计划购电费 + Σ 5×电价×实际紧急购电量，越小越好。
2. **分解指标**: 计划购电费、紧急购电费、紧急购电触发频率、储能利用率。
3. **基准对比**: VSS（相对EV基线）、EVPI（相对完美信息）、执行器对照（DP vs 解析响应 vs MPC）。
4. **隔离验证**: 固定同一日前计划，比较三种执行器的实际成本，量化日内执行层的独立贡献。

## 4. Q2 数学模型：日前决策层（基于历史情景的随机优化）

> **架构说明**：本节定义日前层（0:00，基于历史情景），决定计划购电量 E_plan(t)。**关键建模原则**：日前层优化 E_plan 时，必须按照"日内DP执行器实际会如何运行"来评估期望成本，避免假设储能可以提前知道未来情景（信息泄露）。日内执行层见 §5。

### 4.1 索引与集合

- 时段 t ∈ {1,…,144}，Δt = 1/6 h（继承Q1）。
- 规划日 d ∈ {2025.2.1, …, 2025.12.31}（334天），逐日独立求解。
- 情景 s ∈ S_d：第 d 天当天负载/光伏的候选实现集合，由 d 之前的历史**联合残差**构造（见 §4.9）。情景概率 π_s，Σπ_s=1。

### 4.2 参数

| 符号 | 含义 | 来源 |
|------|------|------|
| Price(t) | 时段t电价 (元/kWh)，全区间每天相同 | 附件1 |
| Load_d^s(t) | 第d天时段t负载 (kW) 在情景s下的取值 | 附件2历史构造 |
| PV_d^s(t) | 第d天时段t光伏 (kW) 在情景s下的取值 | 附件2历史构造 |
| Δt=1/6, η=0.9, E_init=6000, E_min=1200, E_max=10800, P_max=5000, POWER_LIMIT=833.33 | 储能核心 | 附录1 / Q1冻结 |
| κ = 5 | 紧急购电电价倍数 | 题目原文 |

### 4.3 决策变量与建模框架

#### 日前层核心决策变量（0:00 锁定，与情景无关）

- **E_plan(t) ≥ 0**：时段t的计划购电量 (kWh)，t=1..144。**这是唯一必须"此时此刻"确定的量**（题目：其他时段购电费按计划购电量计算）。

#### 建模框架：策略优化视角

日前层的目标是找到最优计划购电量 E_plan*，使得：

$$
\boxed{E_{plan}^* = \arg\min_{E_{plan}} \left[ C_{plan}(E_{plan}) + \mathbb{E}_{\xi \sim \mathcal{D}}[C_{emg}(E_{plan}; \pi_{DP})] \right]}
$$

其中：
- C_plan(E_plan) = Σ_t Price(t)·E_plan(t) 是计划购电费
- C_emg(E_plan; π_DP) 是在给定E_plan下，**DP执行器π_DP实际运行时**的紧急购电费用
- ξ ~ D 表示真实负载/光伏从未知分布 D 中实现
- E[·] 通过历史情景样本近似：E[·] ≈ (1/M)Σ_s [·在情景s下的值]

**关键**：这与标准两阶段随机LP的区别在于——我们**不在日前层直接优化情景相关的储能变量C_t^s, D_t^s**（那会导致储能"看到完整未来情景"），而是承认**储能将由因果DP执行器π_DP在实时运行**，日前层只需优化E_plan使得DP执行器实际运行下的期望成本最小。

#### 实现方式：情景模拟 + DP执行器评估

对每个候选 E_plan：
1. 对每个历史情景 s ∈ {1,...,M}：
   - 模拟该情景下，DP执行器从 t=1 到 t=144 的实际运行
   - 记录该情景下的紧急购电总费用 C_emg^s
2. 计算期望紧急费用：Ē_emg = (1/M)Σ_s C_emg^s
3. 总成本 = C_plan + Ē_emg

通过优化算法（如梯度下降、采样优化、或简化LP近似）搜索最优 E_plan。

> **简化实现**：为保持LP凸性与计算效率，实际实现中可采用**简化LP近似**——在日前层用"理想化储能响应"（如解析响应公式）快速评估期望紧急费用，得到E_plan后，再用DP执行器实际运行。虽然这会导致日前评估与实际执行存在偏差，但通过历史回测验证该偏差可接受（见§7风险R-Q2-8）。此简化使日前层仍为标准LP，计算高效。

### 4.4 简化LP实现（日前层计算方案）

为保持计算效率和凸性，实际实现采用如下简化LP方案：

#### 决策变量

**第一阶段（与情景无关）**：
- E_plan(t) ≥ 0：计划购电量 (kWh)

**第二阶段（每情景一套，仅用于日前评估）**：
- E_charge^s(t) ≥ 0：情景s下时段t充电量 (kWh)
- E_discharge^s(t) ≥ 0：情景s下时段t放电量 (kWh)
- E_storage^s(t)：情景s下储电量 (kWh)
- E_emg^s(t) ≥ 0：情景s下紧急购电量 (kWh)

> **⚠️ 建模说明**：此处第二阶段储能变量 C^s, D^s **仅用于日前层快速评估期望成本，不代表实际执行**。实际执行时，储能由§5的DP执行器按因果规则实时决定。这种简化会导致"日前评估的储能响应"≠"实际DP执行的储能响应"，从而引入系统性偏差（通常是日前层低估紧急购电成本，见§7风险R-Q2-8）。但此简化保留LP凸性，计算高效，且通过历史回测验证偏差可接受。

#### 目标函数

$$
\min_{E_{plan}, \{E^s\}} \; \sum_{t=1}^{144} Price(t)\, E_{plan}(t) \;+\; \sum_{s=1}^{M} \pi_s \sum_{t=1}^{144} \kappa\, Price(t)\, E_{emg}^{s}(t)
$$

κ=5，π_s=1/M（等权情景）。

### 4.5 约束

**(A) 电力平衡（每情景每时段，允许弃光，继承Q1"≥"口径 + 紧急购电项）**：

$$
E_{plan}(t) + E_{emg}^{s}(t) + PV_d^{s}(t)\,\Delta t + \eta\, E_{discharge}^{s}(t) \;\ge\; Load_d^{s}(t)\,\Delta t + E_{charge}^{s}(t),\quad \forall s,\forall t
$$

供给 = 计划购电 + 紧急购电 + 光伏 + η·放电；需求 = 负载 + 充电。紧急购电 E_emg 正是"计划+光伏+储能不足以覆盖真实负载时"补的缺口。

**(B) 储能状态方程（每情景，继承Q1：入池 +η·C，出池 −D）**：

$$
E_{storage}^{s}(t) = E_{storage}^{s}(t-1) + \eta\, E_{charge}^{s}(t) - E_{discharge}^{s}(t),\quad E_{storage}^{s}(0)=6000
$$

**(C) 容量约束**： 1200 ≤ E_storage^s(t) ≤ 10800，∀s,∀t （继承Q1）

**(D) 功率约束**： 0 ≤ E_charge^s(t), E_discharge^s(t) ≤ 833.33，∀s,∀t （继承Q1）

**(E) 独立日边界假设（⚠️ 假设，非题目明确要求）**： 

$$
E_{storage}^{s}(144) = 6000,\quad \forall s
$$

**说明**：此边界条件是从Q1继承的**建模假设**，非Q2题目明文要求。Q2原文仅说"每天0:00制定计划"，并未明确规定每天24:00必须回到6000 kWh。采用此假设的理由：
- 简化计算：每日独立求解，避免全年耦合
- 保守策略：防止过度依赖跨日储能

**局限性**：此假设消除了储能的跨日价值（今天低价充电→明天高价使用），可能低估最优成本。建议进行敏感性分析（见§7风险R-Q2-4）：
- 方案A：全年串联（E_d(0)=E_{d-1}(24)），允许跨日储能
- 方案B：终端价值函数（E(24)自由，末端价值−v·E(24)体现明天价值）

**(F) 非负**： E_plan(t) ≥ 0, E_emg^s(t) ≥ 0, E_charge^s(t) ≥ 0, E_discharge^s(t) ≥ 0

**(G) 非提前性（日前层核心约束）**：

E_plan(t) 对所有情景取同一值（第一阶段变量天然满足）。

> **⚠️ 关键说明**：标准两阶段随机规划的非提前性还要求"储能决策在t时刻只能依赖t时刻之前的观测"，即若两情景在t时刻前观测历史相同，则储能决策必须相同。但实现此完整非提前性需17k+变量的多阶段随机LP，计算成本过高。本方案采用简化：**日前LP中的C^s_t, D^s_t仅用于评估，不施加多阶段非提前性约束；实际执行时由§5的因果DP执行器保证非提前性**。代价是日前评估与实际执行存在模型不一致（见§7风险R-Q2-8）。

### 4.9 历史联合残差情景构造（核心创新点）

**问题**：0:00 时当天真实负载/光伏未知，如何估计其可能分布？

**方法**：历史预测 + 联合残差情景（保留日内相关性与负载-光伏联合误差结构）

#### 步骤1：历史预测（仅用当时可获得信息）

对历史日 i（i < d），使用 i 日当时可获得的历史数据生成预测：
- 负载预测 L̂_i(t)：前35天内同星期日对应时段均值（样本<2天时回退前7天）
- 光伏预测 V̂_i(t)：前7天对应时段均值

这确保历史残差不泄露未来信息。

#### 步骤2：历史联合残差（同日配对）

对每个历史日 i，记录其预测误差序列（144点）：
$$
\epsilon_i^L(t) = L_i(t) - \hat{L}_i(t), \quad \epsilon_i^V(t) = V_i(t) - \hat{V}_i(t)
$$

**关键**：负载误差与光伏误差来自**同一历史日 i**，保留两者的联合相关性（如同一天阴雨天气同时影响两者）。

#### 步骤3：当天情景生成

对规划日 d，先预测 L̂_d(t)、V̂_d(t)（用d之前历史），再用历史残差构造情景：
$$
L_d^{(s)}(t) = [\hat{L}_d(t) + \epsilon_{i(s)}^L(t)]_+, \quad V_d^{(s)}(t) = [\hat{V}_d(t) + \epsilon_{i(s)}^V(t)]_+
$$

其中 i(s) 表示情景 s 对应的历史日（从 d 前30天选取），[·]_+ 截断负值。

#### 步骤4：情景数控制与敏感性分析

**基准方案**：
- 取 d 之前30天的完整残差曲线（M=30个等权情景，π_s=1/M）
- 选择依据：平衡样本新鲜度与统计稳定性

**⚠️ 重要说明**：M=30是基于实践经验的选择，非理论最优。"前30天完整情景"表示**对所选30个历史样本不进行额外情景降维，完整保留样本信息**，但这不等于"无信息损失"——真实概率分布可能需要更多或更少样本。

**敏感性分析要求**（见§7风险R-Q2-5）：
- M ∈ {10, 20, 30, 45, 60}
- 若M=30附近性能最佳，则数据驱动验证选择合理性
- 若结果对M敏感，需论证选择依据或采用自适应窗口

**可选扩展**：
- k-means聚类降维至 k≈10 个代表情景 + 1个极端情景（计算效率优化）
- 加权方案：近期样本权重更高（时间衰减）

**优势**（相对单点期望）：
1. 保留负载-光伏联合误差结构（不会拼出现实不存在的组合）
2. 保留日内时序相关性（整日144点作为一个情景）
3. 数据驱动，无需假设误差分布形式
4. 应对5×非对称惩罚：显式量化缺口风险分布

> 此方法直接继承自参考方案（小红书B方案），已在334天回测中验证有效性。

### 4.10 模型特性与实现说明

- **类型**：基于历史情景的日前随机优化 + 简化LP实现。凸，全局最优（在给定简化假设下）。
- **规模**：第一阶段144变量；第二阶段每情景约 4×144 变量。|S|≈30 个情景 → 总变量 ≈ 144 + 30×576 ≈ 17424。单日 LP 规模适中，HiGHS 秒级可解；334天循环分钟级。
- **与Q1关系**：|S|=1 且情景=真值时，日前层退化为 Q1（含紧急购电项）。
- **输出**：计划购电量 E_plan(t)，锁定全天，作为日内执行层的输入。

**⚠️ 模型一致性问题（风险R-Q2-8）**：

当前实现存在**日前评估层与实际执行层不一致**：
- 日前LP假设储能可以按情景最优调度（C^s_t, D^s_t可随完整情景变化）
- 实际执行时储能由因果DP执行器决定（只能依赖当前状态）

这会导致：
1. **系统性偏差**：日前层通常低估紧急购电成本（因为假设储能比实际更聪明）
2. **E_plan偏低**：日前层认为"储能可以处理更多波动"，倾向少买计划电
3. **实际紧急购电增加**：DP执行器实际运行时发现储能无法完全对冲，触发更多紧急购电

**缓解措施**：
- ✅ V7固定计划对照实验：量化DP执行器相对日前评估的实际表现差异
- ✅ 历史回测验证：确认偏差在可接受范围（如<5%）
- 可选改进：迭代校准（日前层用DP执行器实际响应数据修正评估模型）

**理想方案（计算成本高）**：
完整多阶段非提前性约束 + 日前层直接调用DP执行器评估，但需放弃LP凸性或大幅增加计算量。

## 5. Q2 数学模型：日内执行层（DP价值执行器）

> **架构说明**：日前层已锁定 E_plan(t)，本节定义日内实时执行规则，决定储能充放电以最小化实际紧急购电费用。

### 5.1 执行环境

**已知**（实时观测）：
- 当前时段 t 的真实负载 Load_t、真实光伏 PV_t
- 计划购电量 E_plan_t（已在0:00锁定，不可更改）
- 上一时段末储电量 SOC_{t-1}

**决策**：当前时段的充电量 C_t 或放电量 D_t（互斥）

**目标**：平衡"当前紧急购电代价"与"保留库存的未来价值"

### 5.2 问题定义

定义净缺口：
$$
r_t = Load_t \cdot \Delta t - PV_t \cdot \Delta t - E_{plan}(t)
$$

- r_t > 0：需求超过计划供给，需储能放电或紧急购电
- r_t < 0：供给富余，可储能充电

**三类执行器对比**：
1. **解析响应**（基线）：优先最小化当前紧急购电，不考虑未来价值
2. **MPC**：用预测修正做短期滚动优化
3. **DP价值执行器**（主推）：基于历史情景平均未来价值决策

### 5.3 DP价值执行器原理

**核心思想**：Q1中已建立连续状态DP的价值函数 F_t(e)（命题3.1：凸分段线性，边际价值λ_t(e)=-∂F_t(e) 单调非增）。Q2中虽然当天真值未知，但可用历史情景构造近似未来价值。

#### 步骤1：历史路径价值函数

对每条历史情景 ω（使用§4.9的同一情景集），从日末向前递推：

$$
H_{t,\omega}(e) = \min_{x \in A_t(e,r_{t,\omega})} \left\{ 5 \cdot Price(t) \cdot [r_{t,\omega} + \psi(x)]_+ + H_{t+1,\omega}(e+x) \right\}
$$

其中：
- A_t(e,r)：给定库存e和净缺口r下，允许的内部增量集合（富余时仅能充电、缺口时仅能放电，满足功率与容量约束）
- ψ(x)：效率转换函数（继承Q1，充电x/η、放电ηx）
- 终端：H_{T+1,ω}(e) = -v·e

**终端价值参数 v 的确定**（⚠️ 敏感性分析要求，见§7风险R-Q2-6）：

v≈0.48元/kWh 是跨日库存价值的近似估计，表示"储能在第二天的边际价值"。此参数需要论证依据：

**推荐确定方法**：
1. **理论估计**：v ≈ median(未来低价/高价差) ≈ median(次日低谷电价 vs 高峰电价)
2. **历史统计**：分析历史数据中"末端多1kWh库存能节省多少次日成本"
3. **敏感性分析**：v ∈ {0.3, 0.4, 0.48, 0.6, 0.8}，若结果对v不敏感，则选择合理性得到验证

**当前实现**：v=0.48 基于参考方案经验值，需在论文中补充推导或敏感性验证。

**性质**：每条路径 H_{t,ω}(e) 凸、分段线性、非增（更高库存不会增加补缺费用）。

#### 步骤2：平均未来价值

$$
\bar{H}_t(e) = \frac{1}{M} \sum_{\omega=1}^M H_{t,\omega}(e)
$$

凸性与非增性在平均下保持。通过合并各路径的斜率跳变点，保存为完整折线。

#### 步骤3：实时决策

进入实际时段 t，读取当前真实 r_t 与库存 e = SOC_{t-1}，求解：

$$
x_t^* \in \arg\min_{x \in A_t(e, r_t)} \left\{ 5 \cdot Price(t) \cdot [r_t + \psi(x)]_+ + \bar{H}_{t+1}(e+x) \right\}
$$

恢复交流侧动作：C_t = [x_t^*]_+/η，D_t = [-x_t^*]_+ · η

**解释**：
- 当前放电：减少当前紧急购电（5×电价），但降低未来库存（未来价值 H̄_{t+1} 下降）
- 保留库存：当前多付紧急购电费，但未来可能在更高电价时使用
- DP通过历史情景平均量化"未来可能更值钱"，做动态权衡

> **关键区别**：解析响应只看当前紧急购电最小化；DP执行器考虑跨时段库存价值，是Q1价值函数思想在随机环境下的直接应用。

### 5.4 对照执行器

#### 解析响应（Baseline）

优先最小化当前紧急购电：
$$
C_t = \min\{[-r_t]_+, S, (E_{max} - e)/\eta\}
$$
$$
D_t = \min\{[r_t]_+, S, \eta(e - E_{min})\}
$$

其中 S = P_{max} · Δt = 833.33 kWh。

#### MPC（Model Predictive Control）

对剩余净负荷作衰减修正（用前30天残差估计相邻时段相关系数ρ）：
$$
\hat{N}_{t+j|t} = \hat{N}_{t+j|t} + \rho^j (N_t^{act} - \hat{N}_t)
$$

滚动优化剩余时段，固定已申报 E_plan，目标 min 剩余紧急费 - v·E_T，每次仅执行首个动作。

### 5.5 执行层验证设计（关键）

**固定计划对照实验**：
- 用解析响应方案生成的日前计划 E_plan（或随机LP生成的计划）
- 固定该计划，分别用三种执行器回放真实数据
- 比较：总费用、紧急购电量、紧急购电事件数
- **目的**：隔离执行层贡献，证明DP优势来自日内储能调度，而非偷偷改变日前计划

**完整系统实验**：
- 每种执行器按自身状态重订日前计划（但日前层相同）
- 比较端到端实际成本

> 参考方案在固定计划下验证：DP总成本1402.232万元，低于解析响应1417.424万元和MPC 1427.888万元，降幅≈1.07%。

## 7. 算法步骤、输入输出与验证

### 7.1 求解流程（整合两层架构）

#### Phase 1：日前决策（每天0:00）
1. **历史预测**：用 d 之前历史生成当天预测 L̂_d(t)、V̂_d(t)
2. **情景构造**：取前30天历史残差 ε_i^L(t)、ε_i^V(t)，生成M=30个联合情景
3. **两阶段LP求解**：
   - 第一阶段：E_plan(t)（144变量）
   - 第二阶段：每情景储能+紧急购电（M×576变量）
   - 目标：min 计划费 + 期望紧急费
   - HiGHS求解，Status必须Optimal，否则STOP→A

#### Phase 2：日内准备（每天0:00，基于Phase 1的E_plan）
4. **历史路径DP**：对每条情景ω，从t=144向前递推 H_{t,ω}(e)
5. **平均未来价值**：H̄_t(e) = (1/M)Σ H_{t,ω}(e)，保存为凸折线
6. **保留水平计算**：对每时段t，由H̄_t(e)的负斜率确定动态保留阈值

#### Phase 3：实时执行（每个时段t，按时间顺序）
7. **观测**：真实 Load_t、PV_t，计算净缺口 r_t = Load_t·Δt - PV_t·Δt - E_plan_t
8. **DP决策**：当前库存 e = SOC_{t-1}，求解 x_t^* = argmin{当前紧急费 + H̄_{t+1}(e+x)}
9. **执行**：C_t = [x_t^*]_+/η，D_t = [-x_t^*]_+·η，紧急购电 E_emg_t = [r_t + ψ(x_t^*)]_+
10. **更新**：SOC_t = e + ηC_t - D_t/η

#### Phase 4：回测与输出（每天结束）
11. **结算**：日成本 = Σ_t Price_t·E_plan_t + 5·Σ_t Price_t·E_emg_t
12. **记录**：计划购电、充放电、紧急购电时段与量
13. **循环334天**，汇总全年指标

#### Phase 5：对照实验
14. **固定计划对照**：用同一E_plan，分别执行解析响应/MPC/DP，比较成本
15. **EV基线**：单点期望+裕度，计算VSS
16. **完美信息**：事后已知真值最优解，计算EVPI

### 7.2 输入输出

**输入**：
- 附件1：电价 Price(t)（144点）
- 附件2：真实负载 Load_d(t)、真实光伏 PV_d(t)（334天×144点）
- 附录1：储能参数（η、容量、功率、边界）
- 参数：M=30（情景数）、v=0.48（跨日价值近似）

**输出**：
- result2.xlsx：计划购电量、充放电量、紧急购电量（三工作表）
- 4指定日(3.20/6.21/9.23/12.21)表1/表2/表3
- 全年统计：总成本、计划费、紧急费、触发频率
- 验证指标：VSS、EVPI、三执行器对照结果
- verified_results.json：所有数字来源

### 7.3 验证方式（可证伪检验，阈值有据）

| 检验 | 方法 | 通过标准 |
|------|------|---------|
| V1 储能硬约束 | 逐日逐时复核容量/功率/状态方程/边界 | 继承Q1 validate，全PASS（容差1e-5） |
| V2 真实回测可行性 | 用真实值执行计划，检查是否总能靠紧急购电补齐 | E_emg_real≥0 且平衡满足，无不可行 |
| V3 相对完美信息差距(EVPI) | 对比"事后已知真值的最优(Q1式)成本" vs 日前决策真实成本 | 差距>0且量级合理（日前决策必然≥完美信息） |
| V4 随机解价值(VSS) | 对比 EV基线真实成本 vs 随机规划真实成本 | 随机规划应 ≤ EV基线（否则情景法无价值→回A） |
| V5 紧急购电合理性 | 紧急购电频率与季节分布 | 冬季(高净负载)紧急购电应多于夏季，符合物理直觉 |
| V6 同时充放电诊断 | 检查 C(t)·D(t)≈0 | 理论预期0（正电价+η<1），>0则MILP交叉验证 |
| **V7 执行器对照** | **固定同一E_plan，三执行器实际成本对比** | **DP应≤解析响应≤MPC，证明执行层独立贡献** |
| V8 DP价值函数性质 | 检查H̄_t(e)凸性与非增性 | 所有时段t，H̄_t(e)为凸折线且e↑时H̄_t↓ |

### 7.4 基线与对照体系

**层次化对照体系**：

```
完美信息下界（事后最优）
    ↑ EVPI
日前随机规划 + DP执行器（主方案）
    ↑ 执行器对照（固定计划）
    ├─ 日前随机规划 + 解析响应
    └─ 日前随机规划 + MPC
    ↑ VSS（日前层对照）
EV基线 + 解析响应
    ↑
无储能基线（仅购电）
```

- **完美信息下界**：假设0:00已知真值，给成本理论下界。
- **无储能基线**：只用计划购电+紧急购电，无储能套利。
- **EV基线**：单点期望估计，量化日前层的情景价值（VSS）。
- **固定计划执行器对照**：量化日内层的DP执行器价值，隔离两层贡献。

日前随机规划成本应落在 [完美信息下界, 无储能基线] 之间，且优于EV基线。
