### ✅ 决策点 D-Q2-8：日前评估与实际执行的模型一致性 🔴

**问题描述**（审稿发现的一级问题）:

当前实现存在**日前评估层与实际执行层不一致**：
- **日前LP**：第二阶段储能变量C^s_t, D^s_t可随完整情景变化（假设储能"知道未来"）
- **实际执行**：DP执行器只能依赖当前状态(SOC_t, Load_t, PV_t)，满足因果性

这导致：
1. **信息泄露**：日前LP的储能决策实际上提前知道完整未来情景，违反非提前性
2. **系统性偏差**：日前层低估紧急购电成本（假设储能比实际更聪明）
3. **E_plan偏低**：日前层认为"储能可处理更多波动"，倾向少买计划电
4. **实际成本高于预期**：DP执行器实际运行时紧急购电超过日前评估

**候选方案**:
- **方案A**（最严谨）：完整多阶段非提前性约束，17k+变量的多阶段随机LP
- **方案B**（实用）：承认简化，通过历史回测验证偏差可接受
- **方案C**（理想）：日前层直接调用DP执行器评估期望成本（放弃LP凸性）

**📌 最终决策**: **方案B（简化LP + 历史回测验证）**

**决策理由**:
1. **计算效率**：保持LP凸性，HiGHS秒级求解
2. **实践可行**：参考方案334天回测验证可行
3. **风险可控**：通过V7固定计划对照实验量化偏差
4. **权衡取舍**：计算效率 vs 理论严谨性，选择前者

**缓解措施**（必须实施）:
- ✅ **V7固定计划对照实验**：量化DP执行器相对日前评估的实际表现差异
- ✅ **历史回测验证**：确认偏差在可接受范围（目标<5%）
- ✅ **论文明确说明**：承认日前LP中的C^s, D^s仅用于评估，实际执行由因果DP负责
- 可选：迭代校准（用DP实际响应数据修正日前评估模型）

**论文表述要求**（审稿强制）:

## 日前决策层规格

### 模型类型
两阶段随机线性规划

### 情景构造（历史联合残差）

**步骤**:
1. 历史预测（仅用当时可获得信息）
   - 负载：前35天同星期均值
   - 光伏：前7天均值
2. 历史联合残差：ε_i^L(t) = L_i(t) - L̂_i(t)，ε_i^V(t) = V_i(t) - V̂_i(t)
3. 当天情景生成：L_d^{(s)}(t) = [L̂_d(t) + ε_{i(s)}^L(t)]_+
4. 前30天作为M=30个等权情景

### 决策变量
- **第一阶段**（情景无关）：E_plan(t)，t=1..144
- **第二阶段**（每情景s一套）：
  - E_charge^s(t)：名义充电能量
  - E_discharge^s(t)：名义放电能量
  - E_storage^s(t)：储电量
  - E_emg^s(t)：紧急购电量

### 目标函数
```
min Σ_t Price(t)·E_plan(t) + Σ_s π_s Σ_t 5·Price(t)·E_emg^s(t)
```

### 关键约束
- **非提前性**：E_plan(t) 对所有情景同值
- **电力平衡**（每情景）：E_plan + E_emg^s + PV^s·Δt + η·E_discharge^s ≥ Load^s·Δt + E_charge^s
- **储能约束**（每情景）：继承Q1冻结核心
  - 状态方程：E_storage^s(t) = E_storage^s(t-1) + η·E_charge^s - E_discharge^s
  - 容量：1200 ≤ E_storage^s ≤ 10800
  - 功率：0 ≤ E_charge^s, E_discharge^s ≤ 833.33
  - 边界：E_storage^s(0)=6000, E_storage^s(144)=6000

### 求解器
**HiGHS only**（继承Q1纪律）。不可用或非Optimal → STOP→A

## 日内执行层规格

### 模型类型
动态规划价值函数 + 实时最优决策

### DP价值执行器原理

**Phase 1：历史路径价值函数（每日0:00构建）**

对每条历史情景ω（M=30），从t=144向前递推：
```
H_{t,ω}(e) = min_{x∈A_t(e,r_{t,ω})} { 5·Price(t)·[r_{t,ω}+ψ(x)]_+ + H_{t+1,ω}(e+x) }
```

- A_t(e,r)：给定库存e、净缺口r下允许的内部增量x（满足功率容量约束、单向）
- ψ(x)：效率转换，充电x/η、放电ηx
- 终端：H_{T+1,ω}(e) = -v·e，v≈0.48元/kWh

**性质**：H_{t,ω}(e) 凸、分段线性、非增

**Phase 2：平均未来价值**
```
H̄_t(e) = (1/M) Σ_{ω=1}^M H_{t,ω}(e)
```

保存为凸折线（合并拐点与斜率）

**Phase 3：实时决策（每时段t执行）**

读取真实r_t = Load_t·Δt - PV_t·Δt - E_plan_t，库存e = SOC_{t-1}

求解：
```
x_t* ∈ argmin_{x∈A_t(e,r_t)} { 5·Price(t)·[r_t+ψ(x)]_+ + H̄_{t+1}(e+x) }
```

恢复交流侧动作：
- C_t = [x_t*]_+ / η（充电）
- D_t = [-x_t*]_+ · η（放电）
- E_emg_t = [r_t + ψ(x_t*)]_+（紧急购电）

### 对照执行器

**解析响应（Baseline）**:
```
C_t = min{[-r_t]_+, S, (E_max-e)/η}
D_t = min{[r_t]_+, S, η(e-E_min)}
```

**MPC**:
- 对剩余净负荷作衰减修正：N̂_{t+j|t} = N̂_{t+j|t} + ρ^j(N_t^act - N̂_t)
- 滚动优化剩余时段，固定E_plan，目标min剩余紧急费 - v·E_T
- 每次执行首个动作
