## 人工决策：三个关键问题的裁决

### ✅ 决策1: 效率建模方式

**审查员质疑**: 题目"充放电效率90%"指的是往返效率还是单侧效率？

**题目原文证据**:
- 附录1: "充放电效率: 90%" (problem_parse.md:18)
- 无更多细节说明

**领域惯例分析**:
- 储能领域，"充放电效率"如无特殊说明，通常指**往返效率**
- 往返效率 = η_充电 × η_放电
- 如果往返效率90%，单侧效率 = √0.9 ≈ 0.9487

**原方案问题**:
- 当前方案：双侧效率各90% → 往返效率81%
- 审查员认为过度惩罚储能使用

**📌 最终决策**: 
1. **主方案**: 采用**单侧效率90%** → η_charge = η_discharge = 0.9（往返效率81%）
2. **敏感性分析**: 对比η=0.9(主方案)和η≈0.9487(往返90%解释)两种情况
3. **报告说明**: 在论文中说明"题目'充放电效率90%'按字面理解为充电效率和放电效率各90%，往返效率为81%"

**理由**: 
- 题目原文"充放电效率为90%"，字面理解为单侧效率
- 符合题目表述，无需自行解释为往返效率
- 敏感性分析可展示不同效率解释的影响差异
- 更保守的估计，避免高估储能利用率

## 效率建模修正：解决P0严重问题

### 问题诊断

**原约束**:
```
约束1: E_buy(t) + PV(t)×Δt + E_discharge(t)×η ≥ Load(t)×Δt + E_charge(t)/η
约束2: E_storage(t) = E_storage(t-1) + E_charge(t)×η - E_discharge(t)/η
```

**逻辑矛盾**: E_charge(t)的定义不一致
- 约束1中 `E_charge(t)/η` 暗示E_charge是"电池侧能量"
- 约束2中 `E_charge(t)×η` 暗示E_charge是"电网侧能量"

### ✅ 最终采用方案

**方案A（推荐）**: 定义E_charge和E_discharge为**名义充/放电能量**，效率η统一作用在流出方向（不区分"电网侧/电池侧"，避免措辞矛盾）

**数学表达**:

**决策变量定义**:
- E_charge(t): 时段t的名义充电能量 (kWh)，输入E_charge、损失10%后 η·E_charge 存入电池
- E_discharge(t): 时段t的名义放电能量 (kWh)，电池放出E_discharge、损失10%后 η·E_discharge 供给负荷
- E_buy(t): 时段t从外网购买的电量 (kWh)
- E_storage(t): 时刻t结束时的储能电量 (kWh)

**修正后约束**:

```
η = 0.9  (单侧效率，往返效率81%)

约束1（电力平衡）:
E_buy(t) + PV(t)×Δt + E_discharge(t)×η ≥ Load(t)×Δt + E_charge(t)
∀t ∈ {1, 2, ..., 144}

约束2（储能状态方程）:
E_storage(t) = E_storage(t-1) + E_charge(t)×η - E_discharge(t)
∀t ∈ {1, 2, ..., 144}

约束3（容量约束）:
1200 ≤ E_storage(t) ≤ 10800
∀t ∈ {1, 2, ..., 144}

约束4（功率约束）:
0 ≤ E_charge(t) ≤ 833.33   (5000kW × 10/60 h)
0 ≤ E_discharge(t) ≤ 833.33
∀t ∈ {1, 2, ..., 144}

约束5（边界条件）:
E_storage(0) = 6000
E_storage(144) = 6000

约束6（非负约束）:
E_buy(t) ≥ 0
∀t ∈ {1, 2, ..., 144}
```

**物理解释（效率η统一作用在流出方向，不区分电网侧/电池侧）**:
- 充电：输入 E_charge，损失10%，实际入池 η·E_charge → 状态方程 +η·E_charge
- 放电：电池放出 E_discharge，损失10%，实际供负荷 η·E_discharge → 平衡供给计 η·E_discharge，状态方程 −E_discharge

**效率一致性验证**:
- 充电：名义1 kWh → 入池η kWh
- 放电：出池1 kWh → 供负荷η kWh
- 往返：名义充电1 kWh → 入池η → 若原样放出，供负荷η² kWh
- 往返效率 = η² = 0.9² = 0.81 ✓

### 5000 kW 功率约束的侧别定义（GPT二审要求明确）

**题目原文**: "最大充放电功率为5000 kW"，未区分电网侧或电池侧。

**📌 决策**: 将5000 kW统一理解为**储能装置的名义充放电功率**，直接约束名义能量变量：
```
0 ≤ E_charge(t) ≤ P_max·Δt = 5000 × (1/6) = 833.33 kWh
0 ≤ E_discharge(t) ≤ 833.33 kWh
```

**理由**:
- 题目只给单一"最大充放电功率"，未提供分侧参数，不应自行拆成 `5000·Δt/η` 等隐含假设
- 名义功率口径与变量定义（E_charge/E_discharge为名义能量）一致，避免歧义
- 若审阅认为应约束电池侧/负荷侧功率，属于可放宽假设，可在敏感性分析中讨论（本题不做）

## 禁止售电约束：解决P2问题

**审查员质疑**: 当前约束1用"≥"，可能产生余电

**题目证据**:
- 隐式约束: "购电量必须非负(不能向外网售电,或Q1中未提及售电机制)" (problem_parse.md:77)

**📌 最终决策**: 保持"≥"不等式，但增加经济性解释

**约束保持**:
```
E_buy(t) + PV(t)×Δt + E_discharge(t)×η ≥ Load(t)×Δt + E_charge(t)
```

**理由**:
1. "≥"允许余电（光伏过剩时可弃光）
2. 由于目标是最小化购电成本，且无售电收益，优化器不会故意产生余电
3. 物理上，光伏发电高峰可能超过负荷+储能吸收能力，必须允许弃光

**验证机制**:
- 求解后检查：E_buy(t) + PV(t)×Δt + E_discharge(t)×η - Load(t)×Δt - E_charge(t)
- 如果余量>0，解释为"弃光"
- 在结果分析中报告弃光总量

## 充放电互斥约束：P5问题

**审查员建议**: 先用LP测试，修复效率建模后应自然避免同时充放电

**📌 最终决策**（采纳GPT建议，MILP降级为交叉验证）: 
1. **主模型**: 纯LP，不加互斥约束
2. **理论论证**（写入论文）: 购电价格为正且充放电效率η<1时，同时充放电只产生纯损耗、不降低目标函数；故最优策略不会主动进行无意义的同时充放电。因此LP无需互斥约束即可得到物理合理解。
3. **验证步骤**: 求解后检查是否存在 E_charge(t)>ε 且 E_discharge(t)>ε (ε=0.01)
4. **MILP定位**: 仅作为**物理互斥的交叉验证模型**（若LP异常时对照），**不是**"LP失败后才启用的正式模型"

**理由**:
- "同时充放电"不是LP失败，而是可通过理论排除的现象
- 避免把工程策略误当作模型门槛
- MILP增加144个二元变量，仅在交叉验证时启用

**实测佐证**（GPT用附件1真实数据跑LP）:
| 模型 | η | 最优购电量 | 同时充放电时段 |
|------|---|-----------|---------------|
| LP | 0.9 | ≈59482.70 kWh | 0 |
| LP | √0.9 | ≈57526.24 kWh | 0 |

两种效率解释下LP均无同时充放电，进一步说明Q1无需MILP。

## 最终模型规格

### 决策变量 (576个)
- E_buy(t): 购电量，144个
- E_charge(t): 名义充电能量（入池η·E_charge），144个
- E_discharge(t): 名义放电能量（供负荷η·E_discharge），144个
- E_storage(t): 储电量，144个（t=1~144，E_storage(0)是参数6000）

### 参数
- Price(t): 电价，144个 (元/kWh)
- PV(t): 光伏功率预测，144个 (kW)
- Load(t): 负荷功率，144个 (kW)
- Δt = 1/6 h (10分钟)
- η = 0.9 (单侧效率，往返81%)
- E_init = 6000 kWh (初始和终止储电量)

### 目标函数
```
minimize Z = Σ[t=1 to 144] Price(t) × E_buy(t)
```

### 约束总数
- 电力平衡: 144个
- 储能状态方程: 144个
- 容量上下界: 144×2 = 288个
- 充电能量上下界: 144×2 = 288个
- 放电能量上下界: 144×2 = 288个
- 购电非负: 144个
- 边界条件: 2个 (E_storage(0)=6000, E_storage(144)=6000)
- **总计**: 1442个约束

### 模型特性
- **类型**: 线性规划 (LP)
- **求解器**: PuLP + HiGHS (Python)
- **预期求解时间**: <1秒
- **全局最优**: 保证（凸优化）

## 验证方案（逐时约束验证，不做模糊的能量守恒）

> **修正说明**: 原"能量守恒 Σ(购电+光伏)≈Σ(负荷)+损耗"检查不严谨——因为允许弃光、充放电双侧效率损失、电力平衡用不等号，总量关系不成立。改为逐时验证。

### Check 1: 电力平衡（逐时）
对每个t: E_buy(t) + PV(t)·Δt + E_discharge(t)·η − Load(t)·Δt − E_charge(t) ≥ −ε (ε=1e-6)

### Check 2: 储能状态方程（逐时）
对每个t: |E_storage(t) − (E_storage(t-1) + η·E_charge(t) − E_discharge(t))| < ε

### Check 3: 容量约束（逐时）
对每个t: 1200 ≤ E_storage(t) ≤ 10800

### Check 4: 功率约束（逐时）
对每个t: 0 ≤ E_charge(t) ≤ 833.33 且 0 ≤ E_discharge(t) ≤ 833.33

### Check 5: 边界条件
- E_storage(0) = 6000（参数）
- |E_storage(144) − 6000| < 0.1 kWh

### Check 6: 同时充放电诊断
对每个t: E_charge(t)·E_discharge(t) ≈ 0（阈值0.01 kWh）
- 理论预期: 正电价 + η<1 → 最优解不会主动同时充放电
- 实测: 若出现，用MILP交叉验证（非默认模型）

### 经济性分析（报告用，非验证门槛）
- 与"无储能基准"对比: baseline → optimized → savings，实际节省X%（不预设10-30%）
- 储能利用率、充放电循环次数如实报告

### 弃光量（报告用）
- 逐时余量 = E_buy(t)+PV(t)·Δt+E_discharge(t)·η − Load(t)·Δt − E_charge(t)
- 余量>0 解释为弃光，报告全天弃光总量

Q1建模的方法选择依据4篇核心文献（详见 `related_paper_analysis.md`，书目已Crossref核实）:

方法选择结论: Q1属于确定性、单目标、线性的微网经济调度问题，LP是文献公认的首选，无需元启发式算法。
