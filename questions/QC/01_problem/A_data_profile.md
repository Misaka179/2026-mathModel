## 4. 数据预处理需求

### 4.1 必需预处理

1. **时间索引化**
   - 将时间列转换为索引 t = 1, 2, ..., 144
   - 处理"0:00+1"为第144个时间点

2. **单位转换**
   - 功率(kW) → 电量(kWh): E = P × Δt，其中 Δt = 10min = 1/6 h
   - 示例: Load(t) kW → Load(t) × 0.1667 kWh

3. **数据提取**
   ```python
   Price = array[144]     # 电价数组
   Load = array[144]      # 负载数组
   PV = array[144]        # 光伏预测数组
   ```

### 4.2 建议的辅助计算

1. **净负载计算**
   ```python
   NetLoad(t) = Load(t) - PV(t)  # kW
   ```

2. **电价时段分类**
   - 谷时段: Price < 0.5 元/kWh
   - 平时段: 0.5 ≤ Price < 1.0 元/kWh
   - 峰时段: Price ≥ 1.0 元/kWh

3. **储能理论需求**
   - 最大充电需求 = max(NetLoad < 0 的累计)
   - 最大放电需求 = max(NetLoad > 0 的累计)

### 6.1 电价特征

**建模启示**:
