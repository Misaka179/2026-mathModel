## 1. 能量平衡方程推导

### 1.1 模型定义

根据代码审查（q3_model_scenario_v1.2.py:1364），模型中：
- `E_charge, E_discharge`：功率 (kW)
- SOC更新：`SOC[t] = SOC[t-1] + η·charge·DT - discharge·DT`

### 1.2 正确的能量平衡方程

**完整形式（含弃光）**：
```
E_grid + E_PV + E_discharge = E_load + E_charge + E_curtail
```

**不含弃光形式（错误）**：
```
E_grid + E_PV + E_discharge = E_load + E_charge  [会产生闭合误差]
```

### 1.3 等价形式验证

**形式A（推荐）**：
```
E_grid + E_PV + E_discharge = E_load + E_charge + E_curtail
```

**形式B（含ΔSOC）**：
```
E_grid + E_PV = E_load + ΔSOC + (1-η)·E_charge + E_curtail
```

其中：
- ΔSOC = η·E_charge - E_discharge
- 充电损耗 = (1-η)·E_charge
- 放电损耗 = 0（模型中放电变量是输出功率）

数值验证显示两种形式完全等价（差值<0.01 kWh）。

## 2. 原诊断程序的错误

### 2.1 错误公式

原诊断程序（diagnostic_334days_run.py:132-141）：
```python
energy_in = E_buy + E_pv
energy_out = E_load + delta_SOC + charge_loss + discharge_loss
energy_closure_error = abs(energy_in - energy_out)
```

其中：
- `charge_loss = (1 - ETA) * total_charge`  ✓ 正确
- `discharge_loss = (1 / ETA - 1) * total_discharge`  ✗ **错误**

### 2.2 错误根源

模型中放电变量是**输出功率**，不存在显式放电损耗：
```python
# SOC更新公式
E_storage_actual[t] = E_storage_current + ETA * charge * DT - discharge * DT
```

储能减少量 = `discharge·DT`，不是 `discharge·DT/η`

### 2.3 实际含义

原诊断的"能量闭合误差"实际上等于：
```
误差 = 弃光量 + 放电损耗计算错误
```

由于模型放电无损耗，因此：
```
原报告的"能量闭合误差" ≈ 隐含弃光量
```

## 5. 弃光产生原因分析

### 5.1 模型约束

电力平衡约束是**不等式**（q3_model_scenario_v1.2.py:689-691）：
```python
prob += (E_plan[t] + E_emergency[t] + η·E_discharge[t]·DT ≥ 
         net_load_energy + E_charge[t]·DT)
```

这允许**供给 > 需求**，差额即为弃光。

### 5.2 可能原因

1. **储能容量饱和**
   - SOC达到上限10,800 kWh
   - 无法继续充电，多余光伏只能弃光

2. **充电功率限制**
   - 充电功率上限5,000 kW
   - 光伏高发时段无法全部吸纳

3. **经济优化决策**
   - 低电价时段宁可弃光也不充电
   - 避免后续高电价时段放电损耗

4. **预测偏差**
   - 光伏预测过高
   - 实际执行时供给过剩

### 5.3 证据

从诊断数据（diagnostic_334days.xlsx）观察：
- 0天SOC > 90%（排除系统性饱和）
- 平均紧急购电2.2%（预测总体合理）
- 弃光主要集中在光伏高发日（Day 7/8）

**初步判断**：弃光主要由**瞬时功率不匹配**导致，而非系统性容量不足。

## 6. 改进建议

### 6.1 短期改进（模型层面）

1. **添加弃光惩罚**
   ```python
   # 目标函数中加入弃光成本
   E_curtail = [pulp.LpVariable(f"E_curtail_{t}", lowBound=0) for t in range(N_SLOTS)]
   cost += sum([ALPHA_CURTAIL * price[t] * E_curtail[t] for t in range(N_SLOTS)])
   ```

2. **修改电力平衡为等式**
   ```python
   prob += (E_plan[t] + E_emergency[t] + η·E_discharge[t]·DT == 
            net_load_energy + E_charge[t]·DT + E_curtail[t])
   ```

3. **输出弃光诊断**
   - 每日弃光量
   - 弃光时段分布
   - 弃光率趋势

### 6.2 中期改进（系统层面）

1. **增加储能容量**
   - 当前：10.8 MWh
   - 建议：评估15-20 MWh的效益

2. **增加充电功率**
   - 当前：5 MW
   - 建议：评估7-10 MW的投资回报

3. **改进光伏预测**
   - 使用高精度气象预报
   - 引入实时修正机制

### 6.3 长期改进（策略层面）

1. **需求响应**
   - 光伏高发时段引导负载增加
   - 灵活用电激励机制

2. **多能互补**
   - 考虑氢储能、热储能等
   - 扩展光伏消纳途径
