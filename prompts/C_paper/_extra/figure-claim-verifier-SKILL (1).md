# 图表语义核对（Figure Claim Verifier）

## 概述

对论文中每一张图，将论文对该图的**文字断言**与**图内实际可视化内容**逐项比对，识别"图实不符"的语义偏差。只核对可视化事实，**不评判建模方法好坏、不评价结果优劣、不点评写作风格**。

## 何时使用

- 用户提供论文正文（含图注）+ 全部图片，要求核对图与文字是否一致。
- 论文评审 / 自检阶段，需要逐图验证"图承诺了什么 vs 图实际画了什么"。
- 图与正文分离时，用户提供了"图编号 ↔ 正文位置"对应关系。

## 输入要求

用户需提供：

1. 论文正文（含图注）。
2. 全部图片（或含图片的可定位文件，如 PDF 逐页、绘图脚本输出目录）。
3. 若图与正文分离，提供"图编号 ↔ 正文位置"对应关系。

## 核心原则

- 一切结论只依据**图内可见信息**，禁止脑补或推断图内没有的内容。
- 判断标准是"断言 vs 图实"是否一致，不是"结论是否科学"。
- 图内信息不足时必须如实标记"无法判断"，禁止猜测填补。

## 工作流程（严格循序执行，不得跳步）

### 步骤 1：图表清点与定位

扫描全文，输出全部图表清单，字段：图编号、所在章节/段落、图注原文。

- 确认无遗漏、无编号错位。
- 若发现编号错位、缺图、图注与图不符，记录到结构性问题的独立清单（见步骤 6）。

### 步骤 2：断言抽取（逐图执行）

对每一张图，从以下位置抽取与该图直接相关的全部断言句：

- 图注
- 正文中引用该图的句子
- 结论部分

**判定标准——只有满足以下任一条的句子才算断言，纳入核对：**

| 类别 | 承诺内容 |
| --- | --- |
| 趋势方向 | 增大/减小/先升后降/先降后升/收敛/发散 |
| 单调性 | 单调、非单调、存在局部反弹/平台期 |
| 极值 | 峰值/谷值出现的位置与取值 |
| 量级 | 数值范围、数量级、百分比区间 |
| 相对大小 | A高于/低于/接近B，多组曲线的排序 |
| 不确定度 | 误差条、置信区间、波动幅度 |
| 标注 | 坐标轴名称与单位、图例含义、特定标注点的含义 |

**跳过不纳入核对的句子**：研究动机、方法介绍、通用背景、主观评价，以及任何不对应可视化事实的文字。

**每条断言记录格式：**
- 断言原文（逐字引用，不得改写）
- 出处位置（图注 / 正文第 X 段 / 结论）

### 步骤 3：断言拆解为核对维度

将每条断言拆成若干个"原子事实"逐项列出。

示例：断言"误差随 k 增大单调下降"→ 拆为：
1. 横轴变量是否为 k；
2. 随 k 增大曲线是否整体下降；
3. 是否全程单调（有无局部反弹/平台）；
4. 是否每条曲线都满足（多组对比时）；
5. 下降幅度/数值范围是否与正文一致。

### 步骤 4：打开图核验（逐图执行）

逐一打开对应图片，严格依据图内可见信息，按步骤 3 的核对维度逐项比对：

- **趋势方向**：看曲线走向、柱高变化、点位排列。
- **量级**：对照坐标轴刻度、数值标签。
- **标注**：核对坐标轴名称与单位、图例、图中文字标注。

若某维度图内信息不足（无刻度、曲线过密、分辨率不足、图被裁剪），如实标记"无法判断"，**禁止脑补或推断**。

### 步骤 5：输出每张图的核对记录（固定格式）

对每张图输出以下结构：

```
- 图编号 / 图注原文
- 断言清单（逐条含出处）
- 核对结果表
- 不一致项说明
```

**核对结果表（每张图一张表）：**

| 断言原文 | 核对维度 | 图内实际表现 | 结论（一致/不一致/无法判断） | 证据（引用图内具体特征） | 风险等级（高/中/低） |
| --- | --- | --- | --- | --- | --- |

**不一致项说明**：明确指出差异性质，例如：方向相反、量级差数量级、缺标注、图例错位、编号错位等。

### 步骤 6：输出汇总审计报告

- **统计**：共 N 张图、一致 X 张、不一致 Y 处、无法判断 Z 处。
- **高风险不一致项清单**（按风险等级降序）。
- **每处不一致的最小化修订建议**：明确推荐"改图"还是"改文"，并说明理由。
- **结构性问题的独立清单**：图表编号错位、图表缺失、图注与图不符等。

### 步骤 7：输出完毕，等待用户指令

用户可要求：

- 针对某张图深入复查；
- 按指定格式（表格/清单）导出核对结果；
- 对修订建议生成修改后的图或文字。

## 常见错误与规避

| 错误 | 规避方法 |
| --- | --- |
| 断言抽取时改写原句 | 必须逐字引用原文 |
| 把方法评价当断言 | 严格按步骤 2 判定标准筛选 |
| 图内看不清却强行判断 | 标记"无法判断"，禁止脑补 |
| 跳到修改建议而不先出核对表 | 严格按步骤 5 → 6 顺序执行 |
| 合并多张图的核验结果 | 逐图独立核验、独立记录 |

## 输出产物

- 默认在对话中直接输出步骤 5、6 的内容。
- 如用户要求导出，保存为 `reports/FIGURE_CLAIM_VERIFY_REPORT.md`（结构：概述/图清单/逐图核对记录/汇总审计/结构性问题清单）。
