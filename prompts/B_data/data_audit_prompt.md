# Prompt Name: Data Audit

## Purpose
G3 数据阶段：对原始数据做深度审计与清洗，产出可追溯的数据质量报告，供下游代码生成（G3.5）与论文写作参考。基于 `data-auditor-cleaner` skill 的输出做「深度复核 + 提炼人工决策点」，不重复 skill 已做的清洗。

## Input
- `01_problem/problem_definition.md`（A 交付的问题定义与数据说明）
- `02_model/model_decision.md`（A 的人类模型决策，末尾 MODEL FROZEN）
- `02_model/model_spec.md`（冻结模型规格，含「数据输入 / 清洗要求 / 禁止修改的部分」）
- `03_data/` 下的原始数据附件（xlsx/csv/json，只读）

## Output
- `03_data/data_audit.md`（按 `templates/data_audit.md`）
- `03_data/cleaned_data/` 清洗后数据副本
- 若生成清洗脚本：`04_code/scripts/`

## MUST
- 先调 `data-auditor-cleaner` skill，再在其输出基础上补业务逻辑检查
- 按下方「15 维度」逐项检查，给出定量结论（缺失率、VIF、ADF p 值等），不用「大概/基本/大致」
- 每个 🔴 风险都明确「是否阻塞进入 G3.5」
- 异常值/缺失值只标注 + 提建议，不自行删除
- 检查数据是否满足 `model_spec.md` 中 A 冻结模型的核心假设

## MUST NOT
- 不得修改原始数据文件（只读）
- 不得重复 `data-auditor-cleaner` 已做的清洗
- 不得编造缺失数据 / 自行决定删除异常值
- 不得在 `model_decision.md` / `model_spec.md` 未交付时开工（上游未冻结）

## 15 维度检查清单

| # | 维度 | 要回答的问题 |
|---|---|---|
| 1 | 数据来源 | 实测/调查/模拟？有无采样偏差？ |
| 2 | 样本量 | 总量、各子问题量、时间跨度是否满足模型最低需求？ |
| 3 | 缺失值 | 缺失率、模式（MCAR/MAR/MNAR）、对目标变量影响？ |
| 4 | 重复记录 | 完全/部分重复数量，是否合理？ |
| 5 | 异常值 | 极端值数量、检出率、是否真实极端事件？ |
| 6 | 单位一致性 | 关键变量单位是否统一？ |
| 7 | 数据类型 | 数值/分类/时间类型是否正确？ |
| 8 | 分布特征 | 正态/偏态/多峰？偏度峰度？ |
| 9 | 时间结构 | 频率、季节性、趋势、断点？ |
| 10 | 空间结构 | 有无空间自相关（如适用）？ |
| 11 | 变量关系 | 多重共线性？VIF/相关系数？ |
| 12 | 数据泄漏 | 未来信息是否泄入训练集？ |
| 13 | 样本代表性 | 训练/测试分布是否一致？ |
| 14 | 模型假设匹配 | 数据是否满足所选模型核心假设？ |
| 15 | 参数可估计性 | 模型参数能否从数据稳定估计？ |

## Human Decision Gate
以下情形**必须停下交 A / 人拍板**，AI 不得自行决定处理方式：
- 缺失率 >20% 且为 MNAR；>10% 无法解释的重复记录
- 数据严重违反模型核心假设（如残差严重非正态）
- 检测到时间序列结构断裂；样本量不足模型最低需求

## Chorus
关键判定（缺失/异常值处理、数据变换、共线性、模型假设匹配）用 B 的 `data-review` 模板做多模型复核；平票时交人裁决。意见仅作辅助，最终归人。

## Validation
- 15 维度全查完，每项有定量证据
- 原始 → 清洗 → 最终 过程可追溯，清洗前后样本变化已量化
- 报告引用的图/文件实际存在
- 🔴 风险已标注是否阻塞后续流程

## Output Path
`questions/Qx/03_data/data_audit.md`
